How to use

Letterhead uses the same station branding as invoices and reports.

Blank stationery

Leave subject and body empty, then use Print blank or Download blank. Useful for handwritten notes or filling later in Word. Blank sheets are not added to history.

Typed letter

Enter a date and subject, type the body, then Save letter, Print letter, or Download letter. Save stores a PDF in Google Drive. The database keeps only the date, subject, and Drive link.

Letter history

View opens the Drive PDF in a popup, so the list stays where it was. Download saves that PDF. Print is in the popup. Letter text is not kept in the database after archive. Only admins can delete a letter, and that also deletes the Drive PDF.

PDF files

Saved letters have Download for the Drive PDF, and View opens that PDF on this page. While composing, Print → Save as PDF still works, and the Word buttons download a .doc file.

Update branding

Change name, address, GSTIN, or contact details in Settings → Station & branding. The letterhead updates on the next load.
